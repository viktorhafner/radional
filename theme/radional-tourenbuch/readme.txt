=== Radional Tourenbuch ===
Version: 1.6.0
Benötigt: WordPress 6.7, PHP 7.4, Eltern-Theme „Twenty Twenty-Five“
Lizenz: GPLv2 oder später

Tourenbuch-Design für radional.at. Child-Theme von Twenty Twenty-Five.

== Was es mitbringt ==
* Startseite: neuester Bericht groß, die nächsten fünf darunter, die Karte
  (Plugin „Radional Karte“), ein Fotostreifen und die Bucket List.
* Beitragsseite: Überzeile, Vorspann, Eckdaten, Steckbrief neben dem Text,
  vorheriger und nächster Bericht.
* Vier Bausteine im Block-Editor (Kategorie „Theme“): Überzeile, Eckdaten,
  Vorspann, Steckbrief. Sie lesen die Werte aus dem Kasten „Karte
  (Challenge-Ort)“ im Beitrag (Art, km, Hm, Ort).
* Schriften (Montserrat, Cormorant Garamond) liegen im Theme – es wird nichts
  von Google geladen.

== Vorspann ==
Der kursive Vorspann unter dem Titel erscheint nur, wenn im Beitrag unter
„Auszug“ ein eigener Text steht. Ein automatischer Auszug würde nur den ersten
Absatz wiederholen.
